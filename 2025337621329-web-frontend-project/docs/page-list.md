> 需要页面：登录页、商品/下单表单页、订单列表页、订单详情页

## 页面1：登录页
- 页面目标：完成模拟登录，进入系统
- 主要区域元素：账号输入框、密码输入框、登录按钮、错误提示区域
- 用户主要操作：输入账号密码，点击登录
- 数据来源：前端模拟mock接口
- 状态
  - 正常：表单可输入，点击登录请求接口
  - 空状态：输入框为空
  - 错误状态：账号密码错误提示；网络请求失败提示
- 跳转：登录成功跳转到【商品下单页】

## 页面2：商品&订水表单页（表单页）
- 页面目标：选择桶装水，提交订水订单
- 主要区域元素：桶装水商品选择卡片、楼栋输入框、寝室号输入框、订购桶数输入框、备注输入框、提交订单按钮、表单提示
- 用户主要操作：选择水，填写寝室信息，提交订单
- 数据来源：商品数据来自mock；提交订单调用新增订单模拟接口
- 状态
  - 正常：表单填写完成，可提交
  - 空状态：必填项为空，提交给出校验提示
  - 错误状态：接口提交失败，展示错误提示
- 跳转：订单提交成功跳转到【订单列表页】

## 页面3：订单列表页（列表页）
- 页面目标：展示当前用户全部订水订单
- 主要区域元素：订单列表卡片、状态筛选按钮、空提示组件
- 用户主要操作：浏览订单，点击订单跳转到详情
- 数据来源：调用获取用户订单mock接口
- 状态
  - 正常：展示多条订单数据
  - 空状态：没有任何订单，显示“暂无订单，快去下单吧”
  - 错误状态：网络请求失败，展示加载失败提示
- 跳转：点击列表项跳转到【订单详情页】

## 页面4：订单详情页（详情页）
- 页面目标：展示单个订单完整信息和配送状态
- 主要区域元素：订单编号、订购商品、寝室地址、桶数、下单时间、配送状态流转信息
- 用户主要操作：查看详情，返回订单列表
- 数据来源：根据订单id调用获取单条订单mock接口
- 状态
  - 正常：展示完整订单信息
  - 空状态：订单id不存在
  - 错误状态：接口请求失败
- 跳转：返回按钮回到【订单列表页】
