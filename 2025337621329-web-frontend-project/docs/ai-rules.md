## AI可以参与什么
1. 帮助生成项目文档初稿、markdown模板。
2. 帮助构思页面结构、数据对象、接口草案。
3. 辅助编写前端HTML、CSS、JS示例代码。
4. 给出业务逻辑实现思路，提供参考方案。

## AI不可以替代什么
1. 不替代人做项目选题、业务逻辑判断。
2. 不替代人理解需求，全部输出内容需要我人工阅读修改，不能直接复制就提交。
3. 不替代分析开发者工具Network、不替代自己观察请求响应。
4. 不能直接把AI生成的全部代码不经思考直接交付作业。

## 必须遵守
1. AI生成所有内容，需要人工校验是否符合本次作业要求。
2. 项目所有数据必须虚构，不能出现真实隐私信息。
3. Git提交、目录结构、tag标签必须由人手动操作。
4. AI输出文档之后，我需要修改调整适配自己的项目。

## 人负责什么
1. 确定项目选题、业务边界。
2. 阅读AI输出，甄别对错，删减修改。
3. 建立文件夹，维护目录结构。
4. 执行git命令，推送Gitee仓库，打hw01标签。
5. 保证提交内容满足作业全部验收标准。
