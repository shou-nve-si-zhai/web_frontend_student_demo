## 项目名称
寝室饮用桶装水订购系统

## 一句话定位
大学生寝室桶装水线上下单、追踪配送状态的Web前端应用。

## 目标用户
在校大学寝室学生，以寝室为单位订购桶装饮用水。

## 核心问题
传统寝室订水靠打电话，容易出现沟通出错、不知道什么时候送水、订单没有记录、无法回看历史消费。本系统解决订水下单、状态跟踪、历史订单查询问题。

## 典型使用场景
1. 寝室水喝完，寝室同学打开网页，选择桶装水型号，填写寝室号，提交送水订单。
2. 提交之后查看订单列表，看水站是否接单、配送中、已送达。
3. 回顾过往订水记录，统计寝室订水次数。

## 为什么适合做Web App
不需要下载App，浏览器直接访问；学生在电脑手机浏览器均可打开；适合表单提交、列表查询、状态展示这类业务场景。

## 项目边界
### ✅ 本项目做什么
1. 用户模拟登录
2. 桶装水商品展示
3. 提交订水订单表单
4. 订单列表、订单详情查看
5. 订单状态展示（待接单、配送中、已送达）
6. 模拟接口请求，前端状态渲染

### ❌ 本项目不做什么
1. 不做真实支付、不接入真实支付接口
2. 不做真实水站后端业务服务，全部mock模拟
3. 不做复杂权限管理，不分水站管理员后台
4. 不做短信通知、消息推送
