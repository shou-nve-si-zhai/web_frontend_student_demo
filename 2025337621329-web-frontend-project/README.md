## 项目简介
面向在校大学生寝室的桶装水订购前端网站。
功能包含：商品浏览、关键词搜索过滤、独立商品详情页、创建订单、注册登录弹窗、个人中心查看我的订单。
全部使用原生HTML+CSS+JavaScript，**不需要后端服务，本地浏览器直接打开运行**；账号、订单使用浏览器`localStorage`本地存储。

## 核心功能
1. **响应式布局**：PC/平板/手机自适应；卡片网格自动列数；sticky吸顶头部；无障碍键盘焦点样式。
2. **全局右上角登录组件（全部页面共用）**
    - 未登录：蓝色圆形按钮显示【登录】，点击弹出居中模态浮窗；弹窗支持`登录/注册`Tab切换。
    - 注册账号：账号密码非空校验，账号重复检测；注册成功自动切回登录表单。
    - 登录成功：圆形按钮文字变为【用户】，点击下拉菜单，菜单包含：`个人中心`、`登出`（移除English、切换主题）。
    - 登出：清除登录标记，按钮恢复为【登录】；状态使用`localStorage`持久保存，刷新页面状态不丢失。
3. **商品搜索**：输入关键词，点击搜索按钮或按下回车键执行过滤，打字过程不执行搜索。
4. **订单模块**
    - 创建订单页：选择商品+桶数自动计算总价；表单校验；未登录下单拦截，自动唤起登录弹窗。
    - 订单数据隔离：不同注册用户的订单互相隔离存储在浏览器本地。
    - 个人中心读取当前登录用户的订单列表展示。
5. **页面互通**：全部页面导航、面包屑、返回按钮，无死链接。

> ⚠注意：本项目为前端模拟，**浏览器清除缓存/无痕模式会丢失注册账号和订单数据，无后端数据库**。

## 运行方式
1. 将6张商品图片放入`images`文件夹，文件名和代码保持一致；
2. 直接双击打开 `pages/index.html`，本地浏览器直接打开即可；
3. 浏览器按 `Ctrl+F5` 强制刷新清除缓存。
